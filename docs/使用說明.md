# web-deck 使用說明

web-deck 用來做「介紹一個網站或產品」的網頁簡報。

- **一個 `index.html` 就是一份簡報**：雙擊就能打開，不用裝任何東西，也不用開伺服器。
- **真網站可以直接放進投影片**：可以從真網站拍一段「點下去、頁面重組」的動畫，也可以把地圖或整個網站嵌進投影片。
- **適合跟 AI 一起做**：看效果圖鑑挑效果、在投影片上標註你想要的樣子，再把整理好的清單貼給 AI。

---

## 需要準備什麼

| 你要做的事 | 需要 |
|---|---|
| 放映、在投影片上直接改字 | **Chrome**（改字存檔只有 Chrome 能用） |
| 從真網站拍頁面動畫、幫簡報截圖檢查 | Node.js 22 以上，以及 Playwright（見下面） |

第一次要用拍攝工具時，在 web-deck 資料夾執行：

```sh
npm install
npx playwright install chromium-headless-shell
```

---

## 開一份新簡報

```sh
node tools/new-deck.mjs ~/talks/我的簡報
```

這個指令會做出一個新資料夾，裡面有三樣東西：

```
我的簡報/
  index.html   ← 你的簡報，所有投影片都在這裡
  deck/        ← 引擎（播放、效果），不用動它
  media/       ← 放截圖、影片
```

用 Chrome 打開 `index.html` 就能看。

這個資料夾可以整包複製、壓縮、寄給別人，拿到的人一樣能直接打開。

---

## 放映時的按鍵

| 按鍵 | 作用 |
|---|---|
| → 或空白鍵 | 下一步、下一頁 |
| ← | 上一頁 |
| G（或點右下角頁碼） | 總覽：看所有投影片的縮圖，點一下就跳過去 |
| 滑到最下面的進度條 | 預覽那一頁的縮圖，點一下就跳過去 |
| R | 重播這一頁的動畫 |
| N | 打開或關閉講稿 |
| F | 全螢幕 |
| E | 編輯模式：直接改字 |
| A | 標註模式：標出想改的地方，交給 AI |

網址後面加 `#12` 會直接打開第 12 頁。

---

## 自己改文字：按 E

1. 按 **E**，可以改的文字會出現黃色虛線框。
2. 直接點進去改。最下面的講稿也可以改。
3. 按 **⌘S**（Windows 是 Ctrl+S）存檔。
   - 第一次存會請你選檔案，請選這份簡報的 `index.html`。
   - 同一個分頁之後再存，就不用再選。
4. 按 **Esc** 離開編輯模式。

改過、還沒存的文字會變成紅框，存好就恢復。存檔只會換掉你改過的那幾段，檔案其他地方一個字都不動。

**如果出現「找不到原文，沒存」**：有時同一段文字在檔案裡出現兩次，又剛好結構不同，程式就分不出你改的是哪一個。這時沒存到的那段會一直保持紅框。你可以改用 A 標起來交給 AI，或直接打開 `index.html` 手動修改。

## 跟 AI 一起做

### 1. 看效果圖鑑挑效果

打開 web-deck 資料夾裡的 `effects.html`。

- 每一頁是一種效果，左邊是示範，右邊是名字、適合的用途，還有一句「跟 AI 說」的範例。
- 第一頁照用途分組，點名字就能跳過去。

挑好之後，跟 AI 說「第幾頁的哪裡用哪個效果」就可以了，例如：

> 第 5 頁右邊的截圖用 pan
> 封面標題用 letters
> 做一頁 bento，六格，各放一張截圖和一句話

### 2. 說不清楚位置時：按 A 標註

1. 按 **A** 進入標註模式。
2. 在投影片上**點一下**標出位置，或**拖拉**框出一塊範圍。
3. 在跳出來的框裡寫下想要怎樣，按 Enter 送出。
4. 可以一次標很多則，換頁也沒關係。
5. 按右上角的「**複製給 AI**」，然後貼給 AI。

複製出來的清單長這樣：

```
1. 第 12 頁〈找得到〉
   元素：img（media/home.png）
   選擇器：.slide:nth-of-type(12) > div.grid2 > img
   框住：元素內 9.6 18.9 24 7.7（x y 寬 高，%）
   想要：聚光燈打在這個標題上
```

AI 拿到頁碼、元素和精確位置，就不用猜你說的「右邊那個」是哪個。

「聚光燈」和「推近」這類需要精確位置的效果，一定要用拖拉框選，不要讓 AI 從截圖猜位置。

### 3. 用 Claude Code 的話

web-deck 附了一個 Claude Code skill。安裝方法：

```sh
ln -s "$PWD/skill" ~/.claude/skills/web-deck
```

裝好之後，你說「做簡報」、「第 5 頁加動畫」，或直接貼上標註清單，Claude 都會照 web-deck 的做法進行：

- 先跟你討論大綱，再開始做。
- 照效果圖鑑寫程式碼。
- 做完自己截圖檢查。

## 放截圖和影片

- 截圖、影片都放進 `media/`。
- 截圖用一般的 `<img src="media/xxx.png">` 放進投影片。
- 整頁播放的轉場影片這樣寫：

```html
<section class="slide video"><video src="media/轉場.mp4" muted playsinline></video></section>
```

翻到這頁時影片會自動播放。

## 從真網站拍「頁面重組」動畫

例如在議題頁點一張專案卡片，卡片長成整頁，標題飛到新頁面的位置。

### 步驟

1. 在簡報資料夾裡建立 `morph.config.mjs`：

```js
export default {
  out: "media/morph-project",                                        // 拍好的素材放哪裡
  from: { url: "https://example.org/list", click: 'a[href="/item/42"]' }, // 起點頁面，以及要點的東西
  to: { url: "https://example.org/item/42" },                        // 終點頁面；不寫就真的點下去
  pairs: [['a[href="/item/42"] h3', "h1"]],                          // 從 A 飛到 B 的元素（標題 → 標題）
  rows: "main section > *",                                          // 新頁面上其他依序浮上來的東西
};
```

2. 在**簡報資料夾裡**執行：

```sh
node ~/web-deck/tools/capture-morph.mjs morph.config.mjs
```

3. 最後它會印出一行 HTML，貼進你的投影片就完成了：

```html
<div class="morph" data-fx="morph" data-src="media/morph-project"></div>
```

### 常用設定

| 設定 | 用途 |
|---|---|
| `wait: "map"` | 頁面有地圖時要加，會等地圖載完再拍 |
| `hide: [".cookie-bar"]` | 拍之前先移除礙眼的東西（彈窗、cookie 提示） |
| `init: () => { localStorage.setItem(...) }` | 在網頁載入前先設定好，讓彈窗不要出現 |
| `from: { scroll: 600 }` | 要點的東西在下面時，先往下捲 |
| `fill: "none"` | 卡片長大時不要底色 |

選擇器可以用 Playwright 的寫法，例如 `'a[href="/p/x"] >> text=專案名稱'`。

### 拍出來怪怪的

- **要點的東西不在畫面裡**：用 `from.scroll` 先捲下去。
- **地圖是灰格子**：加上 `wait: "map"`。
- **有一塊沒浮上來**：超出畫面下緣的部分不會拍，這是故意的。

## 不開瀏覽器也能檢查簡報

```sh
node tools/shoot.mjs ~/talks/我的簡報/index.html --sheet        # 每一頁拍一張，再拼成一張總表
node tools/shoot.mjs index.html 12 --at 0.5,2,4                # 第 12 頁在 0.5、2、4 秒各拍一張
node tools/shoot.mjs index.html bento                          # 用頁面的 id 指定
```

照片會存在簡報資料夾裡的 `.shots/`。AI 也是用這個方法「看」它做出來的投影片。

## 上台前檢查

- [ ] **網路**：地圖（`map`）和真網站（`live`）需要網路。場地沒有 Wi-Fi 的話，改用截圖或頁面重組動畫。
- [ ] **字型**：簡報用的是 Google Fonts，離線時會換成電腦內建的字型，版面可能略有不同。
- [ ] **全螢幕**：按 F。
- [ ] **講稿**：講者自己的螢幕按 N 可以看講稿。
- [ ] **從頭到尾翻一次**：按 G 打開總覽看全部，確認沒有空白頁。

## 更新引擎

web-deck 更新後，想讓舊簡報也用新的效果：

```sh
node tools/new-deck.mjs ~/talks/我的簡報 --update
```

這個指令只會換掉 `deck/` 資料夾，你的投影片和素材都不會動。

## 常見問題

**為什麼不用 PowerPoint 或 Google 簡報？**
介紹網站時，最有說服力的是網站本身。web-deck 可以把真網站的畫面、操作、地圖直接放進投影片，還能拍下「點下去會怎樣」的動畫，這些是一般簡報軟體做不到的。

**可以匯出 PDF 嗎？**
目前不行。web-deck 的動畫是重點，PDF 只會留下靜態畫面。

**手機能看嗎？**
可以打開，但這是為了投影設計的 16:9 畫面，手機上字會很小。

**我想要的效果圖鑑裡沒有？**
跟 AI 描述你想要的樣子，或者按 A 標註。新做好的效果會收進圖鑑，下次就能直接叫名字。
