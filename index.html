02 · 跟 AI 一起做02 · With an AI

說不清楚哪裡？
框起來就好Hard to say where?
Just draw a box

按 A，在投影片上點一下或框一塊，寫下想要怎樣。複製出來的清單有頁碼、元素、精確位置，AI 不用猜「右邊那個」是哪個。Press A, click or box anything on a slide and say what you want. The copied list carries the slide, the element and exact coordinates, so the AI never has to guess which "thing on the right" you meant.

  • 看效果圖鑑挑效果，跟 AI 說「第 5 頁用 pan」就好Pick from the gallery and say "slide 5, use pan"

03 · 一個檔案03 · One file

雙擊就開，
在投影片上直接改字Double-click to open,
edit right on the slide

不用安裝、不用開伺服器、不用 build。整個資料夾壓縮就能寄，用隨身碟也能上台。No install, no server, no build step. Zip the folder and mail it, or present from a USB stick.

按 E 直接在投影片上改字，⌘S 存回檔案。只換掉你改的那一行，其他地方一個字都不動。Press E and type on the slide; ⌘S writes it back. Only the line you changed is replaced, byte for byte.

三步開始Three steps

拿到 slidejamGet slidejam

拍真網站動畫時才需要 Playwright。Playwright is only for capturing real sites.

git clone https://github.com/cooldongdong/slidejam
cd slidejam && npm install

開一份新簡報Start a deck

做出一個資料夾，用 Chrome 打開 index.html。Makes a folder; open its index.html in Chrome.

node tools/new-deck.mjs ~/talks/my-talk

跟 AI 說要什麼Tell the AI

叫效果的名字，或貼上按 A 標好的清單。Name an effect, or paste a list marked with A.

「封面標題用 letters，第 3 頁做一頁 bento」"Use letters on the title, make slide 3 a bento"
