使用流程Workflow

從一句「做簡報」，到上台From "make me a deck" to the stage

slidejam 附了一個 Claude Code skill。你說「做簡報」，它會帶你走六個步驟，每一步都會說現在在第幾步、輪到誰做什麼。這頁把整個流程攤開。slidejam ships a Claude Code skill. Say "make me a deck" and it walks you through six steps, always telling you which step you are on and whose turn it is. This page lays the whole flow out.

準備（只要做一次）Setup (once)

拿到 slidejam，再把 skill 連到 Claude Code。之後在任何資料夾開 Claude Code 都能用。Get slidejam and link the skill into Claude Code. It then works from any folder.

git clone https://github.com/cooldongdong/slidejam
cd slidejam
npm install                      # 拍真網站動畫才需要
npx playwright install chromium-headless-shell
ln -s "$PWD/skill" ~/.claude/skills/slidejam

沒有用 Claude Code 也可以：打開 效果圖鑑 挑效果，把按 A 標註出來的清單貼給任何一個 AI。Not on Claude Code? Pick effects from the gallery and paste the lists you mark with A to any AI.

需要 Chrome（改字存檔只有 Chrome 能用）和 Node.js 22 以上。You need Chrome (saving edits is Chrome-only) and Node.js 22+.

第二份簡報、隔天接著做More decks, and picking up later

每份簡報都是一個獨立的資料夾，裡面有自己的一份引擎。做第二份不會影響第一份。Every deck is its own folder with its own copy of the engine. A second deck never touches the first.

開第二份A second deck

再說一次「做簡報」，選「開新的」，給它另一個名字。Say "make me a deck" again, choose new, give it another name.

~/talks/civictech/
~/talks/misheng/   # 互不影響

隔天、開新對話接著做Tomorrow, in a new chat

說「繼續做 ~/talks/misheng」，或直接貼標註清單。清單第一行就有檔案路徑，AI 會自己找到是哪一份，直接從第 5 步接著改。Say "carry on with ~/talks/misheng", or just paste an annotation list. Its first lines carry the path, so the AI goes straight to step 5.
